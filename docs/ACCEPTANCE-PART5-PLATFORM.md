## 本次新增

1. **步骤化 UI 用例**：AI / STEPS 双模式；11 种步骤；逐步截图；真机确定性执行。
2. **元素库**：TEXT/ID/XPATH/COORD 可复用定位器。
3. **定时任务**：Cron、启停、立即执行、矩阵设备。
4. **多设备矩阵**：手动触发或定时任务为每个 UI 用例×设备生成运行项。
5. **测试报告**：资产统计、通过率、最近运行、失败分类。
6. **设备远程能力**：Shell、应用列表/启动/停止/清除/卸载、文件上传、性能、旋转、占用/释放。
7. **设备分组/Agent 管理**：多分组筛选、成员编辑；Agent 重命名/停用/启用（停用后设备不参与调度）。
7. **步骤证据**：每一步截图写入 MinIO，任务轨迹返回 URL。
